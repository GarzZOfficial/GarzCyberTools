# 🔥 GARZ CYBER TOOLS v3.0

## 📖 **Deskripsi Singkat**

**GARZ CYBER TOOLS** adalah kumpulan tools cybersecurity all-in-one yang powerful untuk ethical hacking, penetrasi testing, dan security research. Dibangun dengan Python 3, tools ini menyediakan berbagai fitur mulai dari hash cracking, encoding/decoding, OSINT, network scanning, hingga password analysis.

---

## 🎯 **Apa yang Bisa Dilakukan Tools Ini?**

### 🔐 **1. Hash Generator & Cracker**
- Generate berbagai jenis hash (MD5, SHA1, SHA256, SHA512, SHA3, BLAKE2)
- Verifikasi hash dengan teks asli
- Hash file (MD5, SHA1, SHA256)
- Rainbow table attack simulation

### 📝 **2. Encoder & Decoder**
- **Base64** encoding/decoding
- **Hexadecimal** conversion
- **ROT13** cipher
- **URL** encoding/decoding
- **Binary** conversion (text to binary & vice versa)

### 🔒 **3. Password Security Analysis**
- Password strength checker (score 0-5)
- Entropy calculation
- Breach database checking via HIBP API
- Custom password policy validation
- Batch password checking
- Password recommendations

### 🗝️ **4. Cryptography Tools**
- Caesar cipher encryption/decryption
- Caesar brute force (crack semua kemungkinan shift)
- XOR encryption (coming soon)
- AES encryption (coming soon)

### 🌐 **5. Network Tools**
- **DNS Lookup** - Domain to IP resolution
- **Reverse DNS** - IP to domain lookup
- **Port Scanner** - Scan common ports (21,22,23,25,53,80,443,3306, etc.)
- **Ping Sweep** - Network host discovery
- Service detection on open ports

### 🕵️ **6. OSINT (Open Source Intelligence)**
- **IP Geolocation** - Track IP location, ISP, organization
- **DNS Records** - Get A, MX, NS, TXT, CNAME records
- **WHOIS Lookup** - Domain registration information
- **Email Validation** - Check email format & MX records
- **Subdomain Scanner** - Discover subdomains

### 💣 **7. Password Cracker (Educational)**
- **Brute Force Attack** - Try all possible combinations
- **Wordlist Attack** - Dictionary attack with custom wordlist
- Progress tracking & time estimation
- Custom character sets

### 🛠️ **8. Utilities**
- **Text Analyzer** - Count characters, words, lines, etc.
- **Strong Password Generator** - Generate secure passwords (8-32 chars)
- **Memorable Password Generator** - Easy to remember passwords
- **System Information** - Display system details
